# Research References

## Project
Developing and Validating a Cost-Effective Network Segmentation and Cyber Resilience Framework for Small U.S. Manufacturing Businesses

## 1. NIST — Security Segmentation in a Small Manufacturing Environment

Organization: National Institute of Standards and Technology (NIST)

Publication: NIST CSWP 28

Official link:
https://csrc.nist.gov/pubs/cswp/28/security-segmentation-in-a-small-manufacturing-env/final

Why this source matters:
This publication directly addresses security segmentation in small manufacturing environments. It provides a foundation for understanding existing approaches and identifying practical implementation questions.

How I plan to use it:
- Understand manufacturing network segmentation
- Compare existing guidance with my proposed framework
- Develop simulated network configurations
- Design repeatable validation tests
